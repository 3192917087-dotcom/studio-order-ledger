# 工作室订单账本

用于按年级记录订单、制作分配、客户收款、成员费用和利润。无需安装，打开网页即可使用。

- 微信 1—4 使用头像区分。
- 实物和论文分别选择成员、填写成员费用。
- 应收与已收分别记录，支持分次收款与收款历史。
- 利润按应收金额减去成员费用合计计算。
- DeepSeek 能读取全部年级，生成经营财报、比较利润和回款、分析成员费用，并支持连续追问；API Key 在当前浏览器保存。
- 新订单的编号与金额默认留空。

## 数据保存

订单、成员名单和设置保存在当前浏览器，不会提交到 GitHub。不同设备或浏览器之间不会自动同步。

从本地文件切换到网页时，先在原账本点击“备份数据”，再在网页点击“恢复备份”。API Key 不包含在备份里，需要在网页首次使用时填写。

## 发布和更新

网站通过 GitHub Pages 发布。推送到 `main` 分支后，自动运行检查并更新网页。

发布内容仅包含网页程序与头像，更新备份和测试数据不会进入网站。

## AI 财务分析

点击“AI 财务分析”即可提问，例如“比较22级和23级的利润与回款”“有哪些低利润订单”“哪些未结清订单值得优先跟进”。“经营财报”等快捷按钮会直接发起分析，“新对话”清除本次对话。

AI 接收当前浏览器所有年级的最新账本汇总。小账本同时提供完整订单明细，大账本通过只读工具按需查询每一笔订单和收款记录；汇总覆盖全部匹配记录，分页数量不影响总金额。分析所需数据会发送给 DeepSeek，API Key 仅作为请求鉴权，不进入账本正文、备份或 GitHub。

三个工具只能统计、查订单和查收款流水，没有写入入口；回答按文本、列表和表格显示，不执行模型返回的代码或 HTML。对话只在本次页面会话内保留，刷新后清除，每次提问重新读取最新数据。

财务口径：订单利润＝应收－全部成员费用，尚未扣税费及运营支出。待收逐订单计算，超收单独列出。成员费用不表示已支付；接单月的账面已收不等于当月实际现金收入。流水中的初始余额、收款和修正分别统计。接单时间较久不等于逾期，账本没有付款截止日期。
