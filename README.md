# 工作室订单账本

用于按年级记录订单、制作分配、客户收款、成员费用和利润。无需安装，打开网页即可使用。

- 微信 1—4 使用头像区分。
- 实物和论文分别选择成员、填写成员费用。
- 应收与已收分别记录，支持分次收款与收款历史。
- 利润按应收金额减去成员费用合计计算。
- DeepSeek 只提供账本查询；API Key 在当前浏览器保存。
- 新订单的编号与金额默认留空。

## 数据保存

订单、成员名单和设置保存在当前浏览器，不会提交到 GitHub。不同设备或浏览器之间不会自动同步。

从本地文件切换到网页时，先在原账本点击“备份数据”，再在网页点击“恢复备份”。API Key 不包含在备份里，需要在网页首次使用时填写。

## 发布和更新

网站通过 GitHub Pages 发布。推送到 `main` 分支后，自动运行检查并更新网页。

发布内容仅包含网页程序与头像，更新备份和测试数据不会进入网站。
